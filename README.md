# UANGKU

Web app sederhana untuk mencatat pemasukan dan pengeluaran bulanan.

## Fitur
- Ringkasan saldo, pemasukan, pengeluaran, rata-rata harian, dan persentase tabungan.
- Tambah transaksi dengan tanggal, kategori, jumlah, dan catatan.
- Filter berdasarkan bulan, sembunyikan nominal, dan hapus transaksi.
- Tampilan responsif untuk ponsel dan desktop.
- Data disimpan di `localStorage` browser, jadi hanya tersedia pada browser/perangkat tempat transaksi dicatat. Ini belum tersambung ke Google Sheets atau akun bersama.

## Jalankan lokal
Buka `index.html` di browser.

## Publikasikan dengan GitHub Pages
1. Buka repository **Settings**.
2. Pilih **Pages** pada menu samping.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/(root)`, lalu tekan **Save**.
5. Tunggu proses deployment selesai. Alamat situs akan terlihat di halaman Pages, biasanya `https://muhammadfarizramadhan13-cmd.github.io/uangku-app/`.

Perubahan pada branch `main` akan diterbitkan oleh GitHub Pages secara otomatis.
